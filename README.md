# YouTube Live Stream Setup for GitHub

## Steps to Upload:
1. Extract/Unzip this file.
2. Go to your GitHub Repository.
3. Click on 'Add file' -> 'Upload files'.
4. Upload the entire `.github` folder (or drag and drop `.github/workflows/live.yml`).
5. Go to Settings -> Secrets and variables -> Actions -> Add `STREAM_KEY`.
6. Go to Actions tab -> Continuous Live Stream -> Run workflow!
